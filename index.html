01. Interactive Systems Lab

Inspect the mechanics behind the benchmarks

BLUE-COMP · Pre-encode compositor · arXiv:2606.28753 & 2607.19515

Stop spending H.265 bits on static sensor noise

BLUE is a pre-encode stale-pixel optical-flow compositor—not a replacement codec and not a learned neural video codec. It holds a persistent background seed frame while preserving live foreground motion masks via DIS optical flow or NVIDIA nvof, making standard H.264/H.265 encoders far more entropy-efficient.

VERDICT v1 · Public Experimental Model · Sep 2026

Calibrated decisions without generating prose

When an application needs a yes/no judgment or a calibrated probability over candidate labels, autoregressive text generation burns latency on punctuation and schema boilerplate. Verdict learns a lightweight correction over a frozen SigLIP2 prior and explicitly publishes both its wins and out-of-domain regressions.

Research-to-Production Approach

How I debug and ship AI systems

01
Define the actual operational objective
Optimize task recall, event accuracy, latency, and throughput-per-watt rather than chasing proxy perceptual scores alone.
02
Profile the real bottleneck first
NPU TOPS rarely tell the whole story—network demux, hardware decode, memory bandwidth, or token decoding often dominate.
03
Eliminate leakage before trusting metrics
Use event-level splits, SHA256 data manifests, and matched baselines so correlated video frames never inflate validation scores.
04
Inspect model internals, not nominal configs
Audit actual quantized parameter coverage and LoRA adapter targets—silent mismatches leave critical layers untouched.
05
Evaluate under serving constraints & keep negative results
Test with production JSON grammars, paired bootstrap intervals, and publish task regressions openly so deployment tradeoffs stay honest.
